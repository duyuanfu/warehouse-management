基于微信小程序的中小型仓库管理系统，后端用 Java 17 + Spring Boot + MyBatis-Plus，数据库 MySQL，前端用微信小程序原生开发。数据库包含员工、往来单位、仓库、货品、入库单、出库单、单据明细、盘点单、盘点明细共 9 张表。核心功能是：员工登录并区分主管/理货员角色；货品增删改查；入库和出库时自动增减货品库存并写入单据明细；盘点时录入实际库存、计算盈亏并更新库存；货品列表实时显示库存。最关键的一点是货品表里加 version 字段做乐观锁，解决多管理员同时修改库存时的冲突，体现多管理员协同。整体只要能跑通“登录 → 货品列表 → 入库 → 出库 → 盘点”这条完整闭环，前后端和数据库能联动，界面简洁即可，本科毕设级别，不需要企业级性能。交付需要完整后端代码、小程序代码、建表 SQL、部署说明
